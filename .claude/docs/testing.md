# Testing

Status:
- **Current**: backend (`apps/api`) and frontend (`apps/web`) checks, run in CI by [.github/workflows/ci.yml](../../.github/workflows/ci.yml).
- **Planned**: Testing Library, Playwright e2e, and recommender evaluation. These become required from the change that introduces their tooling; when that happens, update this file and [CLAUDE.md](../../CLAUDE.md).

## Backend (`apps/api`)

- pytest + pytest-asyncio (`asyncio_mode = "auto"`), with httpx `AsyncClient` over `ASGITransport`. App lifespan runs via `asgi-lifespan`. Fixtures are in `tests/conftest.py`, which sets `APP_ENV=test` so the Taskiq `InMemoryBroker` is used.
- **Unit tests** (`tests/`, no Docker): override FastAPI dependencies, for example `get_health_checks`, instead of reaching real services.
- **Integration tests** (`tests/integration/`, marked `integration`, need Docker): testcontainers starts `pgvector/pgvector:0.8.7-pg17`, the same tag as compose.
- **Do not use SQLite**, because the schema relies on enums, pgvector, and pg_trgm.
- Migrations: every revision must pass the round trip upgrade head → downgrade base → upgrade head (`tests/integration/test_migrations.py`).
- Required coverage as features land:
  - Every endpoint: one success case and its main error cases (401, 403, 404, 422).
  - Authorization: user A cannot modify user B's data.
  - Auth: refresh rotation, reuse detection, logout revocation, CSRF rejection.
- Mock external services (TMDB) at the `app/integrations/` boundary. Tests never call TMDB.

```bash
cd apps/api
uv run ruff check . && uv run ruff format --check . && uv run mypy
uv run pytest -m "not integration"     # fast, no Docker
uv run pytest                          # everything, needs Docker
uv run python -m scripts.export_openapi openapi.json   # after any API change; commit the result
```

## Frontend (`apps/web`)

- ESLint (flat config), `next typegen && tsc --noEmit`, Vitest unit tests (`src/**/*.test.ts(x)`), and `next build`.
- `src/lib/api/schema.d.ts` is generated by `pnpm gen:api`. CI fails if it differs from `../api/openapi.json`.
- Planned: Testing Library for component tests, and Playwright e2e for the critical path (register → search → open title → add to list with a score → see it on `/u/{username}/list` → `/me/recommendations` returns items).

```bash
cd apps/web
pnpm lint && pnpm typecheck && pnpm test && pnpm build
pnpm gen:api
```

## Full stack smoke test

```bash
docker compose -f infra/docker-compose.yml up -d --build
curl -s localhost:8000/api/v1/health      # expect 200 and every check true
curl -s localhost:3000 | grep data-status # expect "ok"
```

## Definition of done

| Change type | Required |
|---|---|
| Backend code | ruff + mypy + pytest pass; new or changed endpoint has tests; `openapi.json` re-exported and [api-contracts.md](api-contracts.md) updated if the contract changed |
| Model / schema | Alembic migration included, and the integration round trip passes; [data-model.md](data-model.md) updated |
| Frontend | lint + typecheck + test + build pass; `pnpm gen:api` run if the API changed |
| Infra / Docker | `docker compose ... up --build` reaches healthy, and the smoke test above passes |
| Recommender | Eval report beats the baseline; `model_version` bumped |
| Docs only | Links resolve; CLAUDE.md ≤ 150 lines |
| Legacy Streamlit (until removed) | `streamlit run app.py` starts, given local artifacts; nothing automated exists |

Never mark a task done while tests are failing. Report failures with the actual output.
